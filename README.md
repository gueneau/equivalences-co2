# Équivalences CO2

Petit outil pour convertir une quantité de CO2e en équivalences concrètes (aliments, trajets, objets fabriqués, usages numériques...).

Saisir une quantité en kg ou en tonnes, choisir une catégorie, et obtenir une phrase de comparaison avec sa source.

## Usage

Ouvrir `index.html` dans un navigateur — aucune dépendance, aucun build, tout est en un seul fichier.

## Hébergement

Servi tel quel via GitHub Pages (fichier `index.html` à la racine).
